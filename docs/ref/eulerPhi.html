      Documentation › Number theory › eulerPhi

      Function of #cas

      eulerPhi

      Euler’s totient φ(n), the number of residues modulo n coprime to n, with a theorem about Mathlib’s Nat.totient.

      #cas (eulerPhi n)
      gives Euler’s totient φ(n) of the natural number n, the number of 0≤i<n coprime to n, and proves Nat.totient n = t.

      eulerPhi computes Euler’s totient, the number of residues modulo n that are coprime to n. The theorem is about Mathlib’s Nat.totient itself, not a function of our own, so a proof about the totient can use the printed value directly.

      Details and Options

      • n is a natural number, a literal or a closed integer expression such as 2 ^ 10. φ(0)=0 and φ(1)=1.
      • The theorem is Nat.totient n = t. Without Hex, CAS.NumberTheory.totient_eq_rangeSum writes φ(n) as a sum of indicators of gcd(n,d)=1 over [0,n), which the kernel evaluates, and n≤100000.
      • With import CASHex.NumberTheory, Hex factors n, and CAS.NumberTheory.totient_eq_of_primeFactorsList computes φ(n)=n/∏p·∏(p−1) from the kernel-checked list of prime factors. The bound on n is then the budget of Hex’s factor search.
      • A closed expression is evaluated with numbers of at most 10000 digits, the most that a call computes.
      • The call is evaluated when it is the whole input of #cas.
      • There are no options.

      Applications (1)

      In a proof, cas proves the equation:

      In[5]:=
      theorem totient_thirty_six : Nat.totient 36 = 12 := by
  cas

#print axioms totient_thirty_six
      Out[5]=

      totient_thirty_six depends on the axioms propext, Classical.choice, Quot.sound.

      Possible Issues (3)

      Without Hex the count runs over all of [0,n), and the call takes n≤100000. The message names the import that computes φ from the factorization:

      In[7]:=
      #cas (eulerPhi 1000003)
      Out[7]=

      Error

      eulerPhi counts the residues coprime to n ≤ 100000 without Hex; for `1000003`, `import CASHex.NumberTheory` computes φ from the factorization

      The expression 10 ^ 10000 / 10 ^ 9998 has the value 100, but 1010000 has 10001 digits:

      In[8]:=
      #cas (eulerPhi (10 ^ 10000 / 10 ^ 9998))
      Out[8]=

      Error

      eulerPhi: `10 ^ 10000` has more than 10000 digits, the most that a call computes

      A call inside another call is not evaluated, since gamma is evaluated only as the whole input of #cas:

      In[9]:=
      #cas (eulerPhi (gamma 3))
      Out[9]=

      Error

      eulerPhi takes integer arguments; `gamma x` is evaluated as the whole input of `#cas (gamma x)`
