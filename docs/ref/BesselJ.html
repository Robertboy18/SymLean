      Function of #cas

      BesselJ

      Proved decimal enclosures of Mathlib’s Bessel function Complex.besselJ at an integer order and a rational point.

      #cas [N d] (BesselJ n q)
      proves a decimal enclosure of width at most 10−d of the Bessel function Jn(q) at an integer order n and a rational q, and prints it.

      BesselJ gives you digits of the Bessel function of the first kind, and a proof that they are right. The function is Mathlib’s Complex.besselJ. The answer is a decimal interval of width at most 10−d, with a theorem that Jn(q) is a real number inside it. The call computes enclosures only, so you always say how many digits you want with [N d].

      Details and Options

      • n is an integer with |n|≤50, q a rational with |q|≤50 and a denominator of at most 1000, and 1≤d≤30.
      • The theorem is ∃ r : ℝ, Complex.besselJ n q = r ∧ a ≤ r ∧ r ≤ b ∧ b - a ≤ 1 / 10 ^ d for the printed interval [a,b], so the width is part of the theorem.
      • The kernel checks a partial sum of the power series with a bound on its tail. The Output line says how many terms of the series the check used.
      • At q=0 the enclosure is a point and the output is the exact value: J0(0)=1, and Jn(0)=0 otherwise. A negative order uses J−n=(−1)nJn, Mathlib’s Complex.besselJ_neg_int.
      • The call computes enclosures only, so #cas (BesselJ n q) is refused and points to #cas [N d] (BesselJ n q). Mathlib’s Complex.besselJ_zero gives the exact value at 0.
      • There are no options.

      Applications (1)

      A proof can take an enclosure as a hypothesis, here a coarser one than the printed interval, and show that J0(1)>0:

      In[5]:=
      theorem besselJ_zero_one_pos
    (h : ∃ r : ℝ, Complex.besselJ (0 : ℂ) (1 : ℂ) = r ∧ 3 / 4 ≤ r ∧ r ≤ 4 / 5) :
    ∃ r : ℝ, Complex.besselJ (0 : ℂ) (1 : ℂ) = r ∧ 0 < r := by
  obtain ⟨r, hr, hlo, -⟩ := h
  exact ⟨r, hr, by linarith⟩

#print axioms besselJ_zero_one_pos
      Out[5]=

      besselJ_zero_one_pos depends on the axioms propext, Classical.choice, Quot.sound.

      Possible Issues (3)

      #cas gives no exact value of BesselJ, and the message points to [N d]:

      In[8]:=
      #cas (BesselJ 0 1)
      Out[8]=

      Error

      `#cas` computes no exact value of `BesselJ n x`; `#cas [N d] (BesselJ n x)` gives its digits

      Mathlib defines Complex.besselJ at every complex order, but the series check is written for integer orders:

      In[9]:=
      #cas [N 5] (BesselJ (1/2) 1)
      Out[9]=

      Error

      BesselJ accepts integer orders

      The point is a rational with |q|≤50 and a denominator of at most 1000:

      In[10]:=
      #cas [N 5] (BesselJ 0 51)
      Out[10]=

      Error

      BesselJ accepts rational points with |q| ≤ 50 and a denominator of at most 1000
