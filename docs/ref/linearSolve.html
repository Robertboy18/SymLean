      Documentation › Linear algebra › linearSolve

      Mode of #cas

      linearSolve

      All solutions of a linear system Ax=b with rational entries, with a theorem that there are no others.

      #cas [linearSolve] (A, b)
      finds all solutions x of Ax=b for the matrix A and the vector b with rational entries, and proves that there are no others.

      A lot of the linear systems I meet arrive as a matrix, and linearSolve takes them in that form. What matters to me is that the report gives every solution, not just one. The answer is a single vector, one solution plus the span of a basis of the null space, or the fact that there is none. Each answer is a theorem about Mathlib’s Matrix.mulVec over ℚ that rules out any other solution, so it tells you what all the solutions are, not only that some vector works.

      Details and Options

      • A is a matrix literal !![a, b; c, d] or a list of rows [[a, b], [c, d]] of any shape. b is a vector ![a, b] or [a, b] with one entry for each row of A. The entries are closed rational expressions such as -3/2, 0.25 or 1/10^15.
      • The theorem is one of three statements over ℚ:
        • one solution x0: ∀ x, A.mulVec x = b ↔ x = x₀;
        • one solution x0 plus the span of independent vectors Vi: A.mulVec x₀ = b ∧ LinearIndependent ℚ V ∧ ∀ x, A.mulVec x = b ↔ ∃ c, x = x₀ + ∑ i, c i • V i;
        • no solution: ¬∃ x, A.mulVec x = b.
      • The kernel decides the equations between literals, and linarith proves the statements about every x from the coordinates of A.mulVec x.
      • For equations in named variables, such as 2*x + y = 1 ∧ x - y = 2, the mode solve takes the system as you write it.
      • The tactic cas proves goals A.mulVec v = b for literals over ℚ.

      Possible Issues (2)

      The right side needs one entry for each row of the matrix:

      In[12]:=
      #cas [linearSolve] (!![1, 2; 3, 4], ![5, 6, 7])
      Out[12]=

      Error

      linearSolve: the right side has 3 entries, the matrix 2 rows

      The mode takes the pair (A, b). For Ax=0, nullSpace takes the matrix alone:

      In[13]:=
      #cas [linearSolve] !![1, 2; 3, 4]
      Out[13]=

      Error

      linearSolve: expected a pair `(A, b)`
