      Options

      Options

      The settings of cas, cega and #cas: the budget of a call, what a report shows, and the trace classes.

      set_option name value in command
      sets an option for one command, declaration or tactic.
      set_option name value
      sets it to the end of the section or file.
      set_option trace.class true in command
      prints the messages of a trace class under the call.

      SymLean works within budgets, because I’d rather have an expensive call stop and say so than hang. When a call would need more work than its budget allows, it stops, and the message names the budget. A box query that is too big is refused before the kernel starts, so it fails at once instead of stalling a build. Two more options choose what a report shows, and the trace classes print the steps of a route.

      Details and Options

      • An option is an ordinary Lean option. With in it holds for the next command, and without it to the end of the section or file.
      • A trace class is an option whose name starts with trace.. Set to true, it prints its messages under the call, in the InfoView and in the output of lake build.

      Options of cas and #cas#

      OptionDefaultWhat it sets
      cas.verbosefalseShows the full report under a suggestion of cas? and cega?, and the derivation trees of #cas reports.
      cas.suggestfalseOffers the first checked statement of a #cas report as an example to paste in place of the command.
      cas.maxDigits2000The most decimal digits that a #cas command or a CEGA query may ask for.
      cas.maxDerivativeSteps512The most recursive steps of the search for derivative rules.
      cas.grindHeartbeats20000The heartbeats, in thousands, of the grind and norm_num fallbacks of bare cas. 0 turns them off.
      cas.maxReadBackWork100000The most read-back steps for checked data over variable types other than Fin.

      Options of cega#

      OptionDefaultWhat it sets
      cega.maxRefinementWork4096The most planner calls of a subdivided query, estimated before any kernel work. Raising it permits a larger search and never changes the depth.
      cega.maxPrecision256The largest Taylor order, number of logarithm terms or number of square-root digits in a query.
      cega.maxDimension8The most coordinates of a box query.
      cega.maxFaceReductions5The most nested reductions by monotonicity. Each one roughly doubles the kernel work.
      cega.maxIntegrationPanels256The most panels of the doubling search of bare cega on an integral. (panels := n) is not capped.
      cega.nativeCertificatesfalseLets cega [fast] and cega [fast, batch := n] check finite certificates with compiled code, which also trusts Lean’s compiler. lake build -R -Kcertificates=fast builds SymLean with it on.

      Options of the optional libraries#

      OptionDefaultWhat it sets
      cas.hexHeartbeats20000With CASHex: the heartbeats, in thousands, of the Hex route of cas. 0 turns the route off.
      cas.oracle.timeout120000With CASOracle: the deadline of one oracle run, in milliseconds.

      Trace classes#

      Trace classWhat it prints
      trace.cega.statedEach kernel check of a stated bound, and its outcome.
      trace.cega.integrationFor bare cega on an integral: the panel count, the method and the precision of the quadrature, and the enclosure.
      trace.cega.nativeThe stages of a finite native certificate.
      trace.cas.fallbackThe complete diagnostics of the grind and norm_num fallbacks in a failure report of cas.
      trace.cas.derivativeRulesThe rules tried on each HasDerivAt goal, and the error of each rule that fails.
      trace.cas.validationThe validation of a proof before it closes a goal, and the replay of a cas? or cega? suggestion.
      trace.cas.profileKernel evaluations, proof validations and axiom checks, each as a profile node of its own. trace.profiler shows them too.
