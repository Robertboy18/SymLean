      Documentation › Linear algebra › transpose

      Mode of #cas

      transpose

      The transpose of a matrix of any shape with rational entries, with a theorem about Mathlib’s Matrix.transpose.

      #cas [transpose] A
      gives the transpose of the matrix A with rational entries, and proves A.transpose = B.

      transpose swaps rows and columns. You need it to form ATA, to test symmetry, or to turn a row vector into a column vector and back. The theorem is A.transpose = B for Mathlib’s Matrix.transpose, which Mathlib writes Aᵀ.

      Details and Options

      • A is a matrix literal !![a, b; c, d] or a list of rows [[a, b], [c, d]] of any shape. The entries are closed rational expressions such as -3/2, 0.25 or 1/10^15.
      • The theorem is A.transpose = B for the matrices over ℚ. The kernel decides it by evaluation (decide +kernel).
      • The tactic cas proves the same equations in a proof.

      Applications (3)

      The transpose as a theorem, with the axioms its proof uses:

      In[6]:=
      theorem transpose_two : !![(1 : ℚ), 2; 3, 4].transpose = !![1, 3; 2, 4] := by
  cas

#print axioms transpose_two
      Out[6]=

      transpose_two depends on the axioms propext, Classical.choice, Quot.sound.

      Possible Issues (2)

      Every row needs the same number of entries:

      In[12]:=
      #cas [transpose] !![1, 2; 3]
      Out[12]=

      Error

      the rows of the matrix have different lengths

      A vector ![1, 2, 3] is not a matrix. Write a row as !![1, 2, 3], as above:

      In[13]:=
      #cas [transpose] ![1, 2, 3]
      Out[13]=

      Error

      expected a matrix `!![a, b; c, d]` or `[[a, b], [c, d]]`
