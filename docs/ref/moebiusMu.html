      Function of #cas

      moebiusMu

      The Möbius function μ(n) of a positive integer from its prime factorization, through the optional Hex library.

      #cas (moebiusMu n)
      gives the Möbius function μ(n) of the positive natural number n, one of −1, 0 and 1, and proves ArithmeticFunction.moebius n = μ, with Hex.

      moebiusMu evaluates the Möbius function and proves the value of Mathlib’s ArithmeticFunction.moebius. Everything about μ(n) is in the prime factors of n: it is 0 when a prime repeats, and (−1)k when n is a product of k distinct primes. So the real work is the factorization, and for that we use Hex, the Lean FRO’s verified computer algebra.

      Hex is optional, and the build of this site leaves it out. The outputs on this page that need Hex are quoted from CASHex/Examples.lean, which the Hex build compiles. To turn Hex on, fetch it with the commands in the Hex guide, build it with lake -R -Khex=on build CASHex, and start your file with import CASHex.NumberTheory.

      Details and Options

      • n is a positive natural number, a literal or a closed integer expression, and μ(1)=1.
      • The theorem is ArithmeticFunction.moebius n = μ for Mathlib’s Möbius function, with μ one of −1, 0 and 1.
      • The proof starts from the factorization Nat.primeFactorsList n = [p₁, …] of factorInteger. When the k primes are distinct, n is squarefree (Nat.squarefree_iff_nodup_primeFactorsList) and μ=(−1)k (ArithmeticFunction.moebius_apply_of_squarefree). A repeated prime gives μ=0 (ArithmeticFunction.moebius_eq_zero_of_not_squarefree).
      • When Hex’s factor search runs out of budget, the call refuses and claims nothing.
      • A theorem about ArithmeticFunction.moebius needs import Mathlib.NumberTheory.ArithmeticFunction.Moebius, which this page imports.
      • There are no options. Without Hex the call refuses, and the message says how to turn Hex on.

      Basic Examples (1)

      Applications (1)

      A proof can take the printed theorem as a hypothesis. μ(n)≠0 says that n is squarefree (ArithmeticFunction.moebius_ne_zero_iff_squarefree). This cell needs no Hex:

      In[3]:=
      theorem squarefree_thirty (h : ArithmeticFunction.moebius 30 = -1) : Squarefree 30 := by
  rw [← ArithmeticFunction.moebius_ne_zero_iff_squarefree, h]
  norm_num

#print axioms squarefree_thirty
      Out[3]=

      squarefree_thirty depends on the axioms propext, Classical.choice, Quot.sound.

      Properties and Relations (2)

      Possible Issues (1)

      Without Hex the call refuses, and the message says how to turn Hex on:

      In[6]:=
      #cas (moebiusMu 1001)
      Out[6]=

      Error

      moebiusMu needs Hex (`-Khex=on`): primality certificates and integer factorization come from Hex; build with `lake -R -Khex=on build CASHex` and `import CASHex.NumberTheory`
