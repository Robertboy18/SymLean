      Documentation › Polynomials › member

      Mode of #cas

      member

      Proves that a polynomial lies in the ideal of given polynomials, and gives it as a combination of them.

      #cas [member x, y, …] f [g₁, …, gₘ]
      proves that the polynomial f lies in the ideal generated by g₁, …, gₘ in Mathlib’s MvPolynomial, and gives f as a combination of them.

      With ideal membership, the proof is something you can write down. If f=c1g1+…+cmgm, then f vanishes wherever the gi do, and the cofactors ci are the proof. member looks for them. It prints f written as such a combination, as with Mathematica’s PolynomialReduce, and the theorem underneath is f ∈ Ideal.span {g₁, …, gₘ}.

      We find the cofactors by dividing f by the lexicographic Gröbner basis of the generators (groebner) and following the derivation of that basis back to the generators. Then ring checks the identity.

      Details and Options

      • The theorem is f ∈ Ideal.span {g₁, …, gₘ} in MvPolynomial (Fin n) ℚ, with the i-th listed variable read as X i, proved by explicit cofactors that ring checks.
      • f and the generators are polynomials with rational coefficients in the listed variables.
      • The cofactors are one choice among many: replacing c1 by c1+hg2 and c2 by c2−hg1 gives the same sum.
      • When the cofactors have more than 2000 terms, the proof goes through the basis, and the output says only that they have more than 2000 terms.
      • A nonzero remainder is a refusal and not a theorem. The basis is not proved to be a Gröbner basis on this route, so the refusal proves nothing about non-membership.
      • The tactic cas proves f ∈ Ideal.span {g₁, …, gₘ} in any commutative ring, with the same cofactors. A certificate with denominators needs a ℚ-algebra, so in ℤ the cofactors must have integer coefficients.
      • With CASOracle.Ideal imported, cas [oracle := sympy] and cas [oracle := sage] ask an external system for the cofactors, and Lean checks the identity. See oracle.

      Applications (4)

      The first example as a theorem about Mathlib’s Ideal.span. Only the three standard axioms are used:

      In[5]:=
      open MvPolynomial in
theorem sq_sub_one_mem_span :
    (X 0 ^ 2 - 1 : MvPolynomial (Fin 2) ℚ) ∈ Ideal.span {X 0 * X 1 - 1, X 0 - X 1} := by
  cas

#print axioms sq_sub_one_mem_span
      Out[5]=

      sq_sub_one_mem_span depends on the axioms propext, Classical.choice, Quot.sound.

      The tactic cas proves the same membership in the real numbers:

      In[6]:=
      theorem sq_sub_one_mem_span_real (a b : ℝ) : a ^ 2 - 1 ∈ Ideal.span {a * b - 1, a - b} := by
  cas
      Out[6]=

      ✓ Lean accepts the proof.

      The cofactors 1 and a have integer coefficients, so the membership holds in ℤ as well, and this proof does not use Classical.choice:

      In[7]:=
      theorem sq_sub_one_mem_span_int (a b : ℤ) : a ^ 2 - 1 ∈ Ideal.span {a * b - 1, a - b} := by
  cas

#print axioms sq_sub_one_mem_span_int
      Out[7]=

      sq_sub_one_mem_span_int depends on the axioms propext, Quot.sound.

      The same cofactors prove that x2=1 follows from xy=1 and x=y, with Mathlib’s linear_combination:

      In[8]:=
      example (x y : ℝ) (h1 : x * y = 1) (h2 : x = y) : x ^ 2 = 1 := by
  linear_combination h1 + x * h2
      Out[8]=

      ✓ Lean accepts the proof.

      Properties and Relations (1)

      The cofactors come from the division by the lexicographic Gröbner basis of the generators, here x−y and y2−1 (groebner):

      In[9]:=
      #cas [groebner x, y] [x*y - 1, x - y]
      Out[9]=

      Gröbner basis of the same ideal (checked)

      x−y,y2−1
      x - y, y^2 - 1
      Domain
      ℚ[x, y] as MvPolynomial (Fin 2) ℚ, with x = X 0, y = X 1
      Input (polynomials)
      x*y - 1, x - y

      ✓ Checked by Lean’s kernel: Ideal of the inputs

      Ideal.span {X 0 * X 1 - 1, X 0 - X 1} = Ideal.span {X 0 - X 1, X 1 ^ 2 - 1}
      The certificate: 2 checked steps

      1. Ideal of the inputs

        Ideal.span {X 0 * X 1 - 1, X 0 - X 1} = Ideal.span {X 0 - X 1, X 1 ^ 2 - 1}

        Checked by Lean’s kernel

      2. Gröbner property of the basis

        ∀ p ∈ Ideal.span {X 0 - X 1, X 1 ^ 2 - 1},
  p ≠ 0 → ∃ g ∈ {X 0 - X 1, X 1 ^ 2 - 1}, MonomialOrder.lex.leadingTerm g ∣ MonomialOrder.lex.leadingTerm p

        Checked by Lean’s kernel

      The computation

      • Gröbner basis

        the reduced basis for the lexicographic order x > y, each element scaled to coprime integer coefficients with a positive leading coefficient; computed by SymLean's Buchberger algorithm, 3 polynomials in the derivation, 2 in the basis

      Possible Issues (2)

      A polynomial with a nonzero remainder is refused. The refusal proves nothing about non-membership, although here x is in fact outside the ideal:

      In[10]:=
      #cas [member x, y] x [x^2, y]
      Out[10]=

      Error

      member: x is not shown to be in the ideal: its remainder modulo the computed lexicographic basis is x. The basis is not proved to be a Gröbner basis, so this proves nothing about non-membership

      In ℤ, a certificate that divides is refused. Over ℚ, a=12(2a), but for a=2 the membership is false in ℤ:

      In[11]:=
      example (a : ℤ) : a ∈ Ideal.span {2 * a, a ^ 2} := by
  cas
      Out[11]=
