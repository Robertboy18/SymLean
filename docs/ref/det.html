      Documentation › Linear algebra › det

      Mode of #cas

      det

      The determinant of a square matrix with rational entries, with a theorem about Mathlib’s Matrix.det.

      #cas [det] A
      gives the determinant of the square matrix A with rational entries, and proves A.det = d for Mathlib’s Matrix.det.

      det evaluates the determinant of a matrix over ℚ. You write the matrix as a Mathlib literal, the report prints the number, and the theorem under it is A.det = d for Mathlib’s Matrix.det over ℚ. Because it is a statement about the same matrix you would write in a proof, it can go straight into one.

      Details and Options

      • A is a square matrix literal !![a, b; c, d] or a list of rows [[a, b], [c, d]]. The entries are closed rational expressions such as -3/2, 0.25 or 1/10^15.
      • The theorem is A.det = d for A as a matrix over ℚ. Mathlib’s norm_det simproc computes the determinant of the literal together with a proof, and Lean’s kernel checks that proof.
      • With Hex, the value comes from Hex’s fraction-free (Bareiss) elimination, and the kernel checks its certificate by evaluation instead of replaying the elimination. The theorem is the same, and the output line says “determinant (Hex’s Bareiss certificate)”. To turn it on, build with lake -R -Khex=on build CASHex and add import CASHex.LinearAlgebra. The Hex guide has the details.
      • The tactic cas proves goals Matrix.det A = d for matrix literals, also over ℤ and ℝ, and proves a determinant with variables as a polynomial identity. A wrong value is refused, and the message shows the value it found.

      Applications (3)

      The determinant as a theorem, with the axioms its proof uses:

      In[6]:=
      theorem det_three : Matrix.det !![(1 : ℚ), 2, 3; 4, 5, 6; 7, 8, 10] = -3 := by
  cas

#print axioms det_three
      Out[6]=

      det_three depends on the axioms propext, Classical.choice, Quot.sound.

      In a proof, cas also evaluates a determinant with variables. The Vandermonde determinant becomes a polynomial identity:

      In[7]:=
      example (a b c : ℝ) :
    Matrix.det !![1, a, a ^ 2; 1, b, b ^ 2; 1, c, c ^ 2] = (b - a) * (c - a) * (c - b) := by
  cas
      Out[7]=

      ✓ Lean accepts the proof.

      A 5×5 determinant over the integers:

      In[8]:=
      example : Matrix.det !![(-1 : ℤ), -1, -2, 3, 0; -2, 4, 0, -5, 1; -4, 1, -2, -1, 0;
    -1, 4, -1, 4, 0; -5, 4, 1, -5, -3] = 228 := by
  cas
      Out[8]=

      Possible Issues (3)

      The matrix has to be square:

      In[12]:=
      #cas [det] !![1, 2, 3; 4, 5, 6]
      Out[12]=

      Error

      det: the matrix must be square

      The entries have to be rational numbers. For a determinant with variables, state it as a goal for cas, as in the Vandermonde example:

      In[13]:=
      #cas [det] !![x, 1; 1, 1]
      Out[13]=

      Error

      expected a rational number, such as -3/2, 0.25 or 1/10^15
