      Mode of #cas

      fourierTransform

      The Fourier transform of a Gaussian in Mathlib’s convention, with a theorem for every frequency.

      #cas [fourierTransform x ξ] f
      gives the Fourier transform of the Gaussian f as a function of ξ, in Mathlib’s convention, and proves it for every real ξ.

      fourierTransform computes the transform of a Gaussian ce−αx2+βx+γ. It covers those and nothing else. Conventions for the Fourier transform differ by factors of 2π from one book to the next, and the first thing to know is which one you are getting. Here it is Mathlib’s, ℱf(ξ)=∫ℝe−2πixξf(x)dx, the one Mathematica uses with FourierParameters -> {0, -2 Pi}. The theorem is about FourierTransform.fourier of f as a complex function, for every real ξ.

      The computation is the one from a first course, completing the square, which gives cπ/αeβ2/(4α)+γ−π2ξ2/α, times the phase e−iπβξ/α when β≠0.

      Details and Options

      • For the printed F, the theorem is ∀ ξ : ℝ, FourierTransform.fourier (fun x : ℝ ↦ (f : ℂ)) ξ = F, with f as written. In Mathlib, 𝓕 f ξ = ∫ x, exp (-2 * π * I * x * ξ) * f x.
      • f is c * exp (-α * x ^ 2 + β * x + γ) with rational c ≠ 0, α > 0, β and γ. The exponent may be written in any form, such as -(x - 1) ^ 2, as long as it is a polynomial of degree 2 in x.
      • The transform is c * √(π / α) * exp (β ^ 2 / (4 * α) + γ - π ^ 2 * ξ ^ 2 / α) times the phase exp (-(π * β * ξ / α) * I), which is left out when β = 0. With α = a / b in lowest terms, the root is printed sqrt(b*pi/a).
      • Parameters, π among them, are refused, and so are products with other functions. The command is also refused inside a section with variables.
      • There are no options. A proof can take the printed theorem as a hypothesis and evaluate it, as under Applications.

      Applications (1)

      The printed theorem as a hypothesis in a proof, evaluated at ξ=0. Only the three standard axioms are used:

      In[5]:=
      theorem fourierTransform_at_zero
    (h : ∀ ξ : ℝ, FourierTransform.fourier (fun x : ℝ ↦ ((Real.exp (-x ^ 2) : ℝ) : ℂ)) ξ =
      ((√Real.pi * Real.exp (-(Real.pi ^ 2 * ξ ^ 2)) : ℝ) : ℂ)) :
    FourierTransform.fourier (fun x : ℝ ↦ ((Real.exp (-x ^ 2) : ℝ) : ℂ)) 0 = (√Real.pi : ℂ) := by
  rw [h 0]
  simp

#print axioms fourierTransform_at_zero
      Out[5]=

      fourierTransform_at_zero depends on the axioms propext, Classical.choice, Quot.sound.

      Possible Issues (4)

      The coefficients are rational, so π in the exponent is refused. Mathlib’s theorem fourier_gaussian_pi gives the transform of exp (-π * b * x ^ 2):

      In[11]:=
      #cas [fourierTransform x ξ] (exp (-pi * x ^ 2))
      Out[11]=

      Error

      fourierTransform: expected c * exp (-α x ^ 2 + β x + γ) with rational c, α, β, γ and α > 0 (parameters are not supported)

      The Gaussian must decay. ex2 is not integrable, and the input is refused:

      In[12]:=
      #cas [fourierTransform x ξ] (exp (x ^ 2))
      Out[12]=

      Error

      fourierTransform: expected c * exp (-α x ^ 2 + β x + γ) with rational c, α, β, γ and α > 0 (parameters are not supported)

      A product with another function is refused, here with cosx:

      In[13]:=
      #cas [fourierTransform x ξ] (exp (-x ^ 2) * cos x)
      Out[13]=

      Error

      fourierTransform: expected c * exp (-α x ^ 2 + β x + γ) with rational c, α, β, γ and α > 0 (parameters are not supported)

      The two variables must be different:

      In[14]:=

      Out[14]=

      Error

      fourierTransform: the variables x and ξ must be different
