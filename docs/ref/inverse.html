      Documentation › Linear algebra › inverse

      Mode of #cas

      inverse

      The inverse of a square matrix with rational entries, or a proof that its determinant is 0.

      #cas [inverse] A
      gives the inverse of the square matrix A with rational entries and proves A⁻¹ = B, or proves A.det = 0 when A has no inverse.

      inverse computes the entries of A−1 over ℚ. The theorem is about Mathlib’s A⁻¹, and here a Mathlib convention matters. That inverse is total, and for a singular matrix it is the zero matrix. A statement A⁻¹ = 0 would then be true and still tell you nothing about an inverse, which is the kind of statement I don’t want a tool to print. So for a singular matrix the report proves A.det = 0 instead.

      Details and Options

      • A is a square matrix literal !![a, b; c, d] or a list of rows [[a, b], [c, d]]. The entries are closed rational expressions such as -3/2, 0.25 or 1/10^15.
      • For an invertible A the theorem is A⁻¹ = B for Mathlib’s inverse over ℚ. The kernel evaluates the product BA and checks that it is the identity, and Matrix.inv_eq_left_inv turns that into the inverse.
      • For a singular A the output is “no inverse” and the theorem is A.det = 0, proved with Mathlib’s norm_det.
      • The tactic cas proves goals A⁻¹ = B for matrix literals over ℚ, and refuses a wrong B.

      ✓ Lean accepts the proof.

      Possible Issues (3)

      The matrix has to be square:

      In[12]:=
      #cas [inverse] !![1, 2, 3; 4, 5, 6]
      Out[12]=

      Error

      inverse: the matrix must be square

      Every row needs the same number of entries:

      In[13]:=
      #cas [inverse] !![1, 2; 3]
      Out[13]=

      Error

      the rows of the matrix have different lengths

      cas refuses a wrong inverse. Here one sign is wrong:

      In[14]:=
      example : (!![(1 : ℚ), 2; 3, 4])⁻¹ = !![-2, 1; 3 / 2, 1 / 2] := by
  cas
      Out[14]=

      Error

      cas: the inverse is !![-2, 1; 3/2, -1/2], not !![-2, 1; 3/2, 1/2]
