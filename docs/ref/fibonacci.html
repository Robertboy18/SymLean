      Documentation › Number theory › fibonacci

      Function of #cas

      fibonacci

      The Fibonacci number Fn, with F0=0 and F1=1, and a theorem about Mathlib’s Nat.fib.

      #cas (fibonacci n)
      gives the Fibonacci number Fn of the natural number n and proves Nat.fib n = F.

      fibonacci uses the convention F0=0, F1=1 and Fn+2=Fn+1+Fn, and the theorem is about Mathlib’s Nat.fib. The interesting part is the cost of the proof. It takes a number of steps that grows with the binary digits of n, not with n itself, because Mathlib’s norm_num extension uses the doubling formulas.

      Details and Options

      • n is a natural number, a literal or a closed integer expression.
      • The theorem is Nat.fib n = F. norm_num proves it with Mathlib’s extension for Nat.fib (Mathlib.Tactic.NormNum.NatFib), which uses the doubling formulas of Nat.fastFib, so the number of proof steps grows with the number of binary digits of n.
      • The value has at most 10000 digits, the most that a call computes.
      • The call is evaluated when it is the whole input of #cas.
      • There are no options.

      Applications (1)

      In a proof, cas proves the equation, here without any axioms:

      In[3]:=
      theorem fib_twenty : Nat.fib 20 = 6765 := by
  cas

#print axioms fib_twenty
      Out[3]=

      fib_twenty depends on no axioms.

      Possible Issues (2)

      Mathlib’s Nat.fib is defined on natural numbers, and a negative argument is refused:

      In[6]:=
      #cas (fibonacci (-5))
      Out[6]=

      Error

      fibonacci takes a natural number as its argument; `-5` is negative

      The value has at most 10000 digits. F47851 has 10000 and F47852 has 10001:

      In[7]:=
      #cas (fibonacci 47852)
      Out[7]=

      Error

      fibonacci: the value has more than 10000 digits, the most that a call computes
